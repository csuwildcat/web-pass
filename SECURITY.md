## Security Considerations

Web Pass is an early-stage project. The security model is still being defined,
so treat everything in this repository as experimental and non-production.

## Best Practices (interim)

- Review code and dependencies before use
- Avoid handling real secrets until the threat model is published
- Prefer local development environments for experiments
- Test thoroughly before integrating into any workflow

## Threat Model (in progress)

A formal threat model will be documented once the new approach is finalized.
